# Домашняя задание к работе номер 4
## Условие задачи:
Тренер формирует стартовый состав из трех игроков с номерами A, B и C. Он считает, что это "счастливая" тройка, если сумма номеров игроков делится на три без остатка. Запишите условие для "счастливой" тройки.
## 1.Алгоритм и блок-схема
1.Начало   
2.Объявление переменных и ввод данных пользователем  
3.Считаем среднее значение  
4.Выделяем целую часть среднего значения  
5.Выделяем дробную часть   
6.Создаем условие floatpart1 != 0, проверяем, если переменная равна 0, то на экран выводим "Счастливая команда", иначе "Не счастливая команда"  
7.Конец
